# 肥鱼哲学馆 · 一根烟的时间

一个用来“勾引桌宠”的深夜哲学小站：一条戴圆眼镜的胖鱼坐在扶手椅里抽烟，思考人生，顺便把 token 账本烧得很好看。

**在线访问：** https://OrsonAndrew.github.io/fatfish-philosophy/

## 它有什么

- **纯 SVG + Canvas 场景**：呼吸、摆尾、眨眼、烟头明灭、烟雾粒子、香烟越抽越短；点一下鱼，它会吐烟圈。
- **28 条原创“鱼生哲学”**：自动一根接一根地思考；支持提问、递烟、换话题、暂停、自动续烟。
- **Token 账本**：累计消耗、本次会话、上下文、香烟数、思考轮数、预估花费，以及最近 14 轮输出柱状图。
- **本地存档**：统计写入 `localStorage`；右上角连点两次“重置账本”清零。
- **响应式 + 无外部依赖**：三个静态文件，手机端会自动把鱼缸放到前面。

## 说明

本页不联网、不调用任何模型。页面上的 token 与费用均为本地模拟估算，**不会真的消耗 DeepSeek token 或产生扣费**。

## 本地打开

双击 `index.html`，或用浏览器打开：

```text
C:\Users\ASUS\Desktop\网页\index.html
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、鱼与场景 SVG |
| `style.css` | 视觉、布局、动效、响应式 |
| `app.js` | 哲学循环、token 账本、烟雾 Canvas、交互 |
